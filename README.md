# 취학전 아동 그림어휘력 검사 (20문항)

브라우저에서 바로 실행되는 단일 HTML 웹앱입니다. 별도 설치나 서버가 필요 없습니다.

## 구성

- **20문항**: 동물, 음식, 탈것, 생활용품 범주별 5문항
- 각 문항은 **정답 1개, 오답 3개**의 4지선다형
- 문항별 반응 시간을 선택 순간부터 밀리초 단위로 기록하고 결과에는 초 단위로 표시
- 결과 대시보드: 총점(20점), 범주별 점수(각 5점), 문항별 정오답 및 반응 시간
- **CSV 내보내기**: 검사일시, 아동/검사번호, 응답, 정오답, 반응 시간, 총점과 범주 점수

## 그림 파일

그림은 로컬 pic 폴더에서 읽습니다. 현재 제공된 로컬 폴더에서 그림 파일을 찾지 못해, 앱은 문항별 그림 파일명과 안내 문구를 표시하도록 제작되었습니다. 아래 이름으로 이미지를 추가하면 다음 실행부터 자동으로 표시됩니다.

## 실행

1. index.html을 Chrome, Edge 등 최신 브라우저로 엽니다.
2. 아동 이름 또는 검사 번호를 선택적으로 입력합니다.
3. 검사 시작 후 각 그림에 맞는 낱말을 선택합니다.
4. 결과 화면에서 점수와 반응 시간을 확인하고 CSV로 내보내기를 선택합니다.

## 유의 사항

본 문항은 교육용/시범용 초안이며 표준화된 임상 또는 진단 검사를 대체하지 않습니다. 연구나 임상에서 사용하기 전에 표집, 난이도, 그림의 문화적 적절성, 신뢰도 및 타당도를 별도로 검토해야 합니다.
